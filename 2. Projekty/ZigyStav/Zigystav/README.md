# ZigyStav – web stavební společnosti

Statický web (HTML + CSS) pro Zigy STAV Brno a.s.

| Soubor | Stránka |
|---|---|
| `index.html` | Domů (úvodní stránka) |
| `onas.html` | O nás |
| `sluzby.html` | Naše služby |
| `reference.html` | Reference |
| `model.html` | 3D model domu (Three.js – otáčení, přiblížení, odkrytí střechy, den/noc) |
| `kontakt.html` | Kontakt a formulář |
| `styl.css` | Společný styl všech stránek |
| `logo.png` | Logo firmy |

Web se otevírá souborem `index.html`. 3D model potřebuje připojení k internetu (knihovna Three.js se načítá z CDN).
